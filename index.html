Final strategy rules

✓ BOS + Order Block + FVG required

✓ Retest/reaction + closed-candle confirmation required

✓ Reclaim/continuation break required before signal

✓ Displacement + liquidity sweep + RSI + ATR confidence filters

✓ Minimum confidence: 3/4 filters

⭐ OTE = Strong signal upgrade

✓ No OTE = Weak signal when 3/4 confidence filters pass

✓ RR ≥ 1:2 using structural SL and actual target

The rules are identical whether you use the signal manually on demo or with Auto execution. Automatic execution remains locked until you connect and arm it.

How the engine reads price

It identifies swing points and BOS, finds the Order Block and FVG, then waits for a retest/reaction, closed-candle confirmation, and a subsequent reclaim/continuation break. OTE is optional: when OTE is present the setup is Strong; when OTE is absent but every other requirement passes, the setup is Weak. A signal is blocked if price bounces back across the reclaim level.

Risk Management

Used for demo planning and signal risk amounts. It does not place orders or calculate broker-specific lot size.

How execution works

When the selected strategy gate is satisfied, the engine requests a Deriv proposal and buys it. Each open contract is then subscribed to in real time; when enabled, the exit manager closes the contract at the signal TP/SL price or the maximum-hold timer. Closing uses Deriv's authenticated sell operation. The TP/SL values are local strategy exit triggers for the multiplier position.

Real execution requires authenticated Deriv API access and is not possible from the public market-data connection alone.
